# Letter Manipulator

Інтерактивний веб-додаток для маніпулювання буквами та текстом.

## 🚀 Можливості

- ✍️ Введення будь-якого тексту та створення інтерактивних літер.
- 🖱️ Перетягування (Drag & Drop) літер по екрану.
- 🔲 Прямокутне виділення (Selection Box) для масового вибору.
- ⌨️ Підтримка `Ctrl` / `Cmd` для вибору кількох окремих літер.
- 🧹 Очищення дошки.

## 🛠 Запуск

Откройте `index.html` в любом браузере или запустите локальный сервер:

```bash
npm start
```
